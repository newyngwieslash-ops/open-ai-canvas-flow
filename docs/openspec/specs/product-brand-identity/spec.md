# product-brand-identity Specification

## Purpose
确保“源铭振跃”作为同一产品身份贯穿界面、后台默认值、系统通信、内置创作能力、文档与分发素材。覆盖新安装和存量配置，防止界面展示已改名而邮件、插件、图片或管理操作仍暴露旧品牌，同时保留实际业务数据及机器可读合同。

## Requirements

### Requirement: 默认产品品牌一致
系统 SHALL 在产品自有的可见文字、默认设置、页面和分享元数据、无障碍标签、助手自述、导出展示、邮件身份和默认协议标题中使用“源铭振跃”，不得向用户展示旧默认品牌或其英文品牌副标。

#### Scenario: 新安装与前端失败降级
- **WHEN** 新安装没有保存外观设置，或前端获取公开外观失败而使用内置默认
- **THEN** 登录、创作、欢迎页、后台、预演、画布助手与元数据均使用新品牌，刷新和导航不闪回旧名

#### Scenario: 系统通信与管理操作
- **WHEN** 读取默认注册协议、通过隔离邮件发送器生成邮件、查看内置作者或恢复默认操作的提示
- **THEN** 用户看到的新默认身份均为“源铭振跃”，测试不发送真实邮件且不执行破坏性的恢复默认操作

### Requirement: 存量设置更新不得覆盖其他配置
系统 MUST 处理仍保存旧品牌的产品全局身份文案及内置内容元数据，使其与新品牌一致；只更新明确品牌字段，不以重置整个配置的方式改名。其他自定义品牌、Logo、媒体、主题、备案、额度、密钥及用户创作内容 MUST 保持原值。

#### Scenario: 旧外观和默认发件人
- **WHEN** 既有实例的品牌、SEO、Agent、默认协议或继承式邮件发件人仍使用旧默认身份
- **THEN** 公开读取、管理读取和通信采用新身份，其他字段无丢失，保存与重启后不重新显示旧品牌

#### Scenario: 自定义配置保护
- **WHEN** 实例采用其他自定义品牌和 Agent，或用户项目、提示词正文、聊天和素材中提及旧名
- **THEN** 这些用户内容及其他品牌保持不变，品牌替换不清库、不清缓存、不改资源归属

#### Scenario: 已安装内置内容
- **WHEN** 现有实例已经安装含旧品牌的官方技能或插件元数据
- **THEN** 官方品牌展示随更新变为新名称，稳定内容 ID 与用户自定义编辑保持可识别且不产生重复安装

### Requirement: 产品自有内容和分发包一致
系统 SHALL 将当前维护的产品说明、内置技能名称、插件作者展示、嵌入文档及分发包内的品牌同步更新。目录或文档改名 MUST 同步真实引用；不能只改包外文件而保留包内旧文案。

#### Scenario: 插件解包与读取
- **WHEN** 检查更新后的插件源码与实际可分发包，或在宿主中读取其作者和说明
- **THEN** 两者均采用新品牌，包的协议、供应商参数、资源路径和导入行为保持有效

#### Scenario: 技能目录和文档
- **WHEN** 读取、嵌入或加载更名后的产品自有短剧技能与文档
- **THEN** 展示名称和说明使用新品牌，引用无断链且稳定技能 ID 不改变

### Requirement: 非文本素材不得遗留旧品牌展示
产品实际引用的图片、截图、SVG、视频及内嵌页面 SHALL 一并检查品牌文字与标识。含旧品牌的产品截图 MUST 从改名后的真实应用重截；第三方 Logo、作者头像、上游许可和真实出处 MUST 不被冒充或抹去。

#### Scenario: 图片与视频中的旧名
- **WHEN** 产品页面或文档引用了含旧品牌像素、字幕或字标的素材
- **THEN** 该素材经过实际检查和更新，交付提供真实页面证据，不用生成的伪界面截图替代产品验收

### Requirement: 机器标识与既有数据保持可用
品牌显示替换 MUST 不改变公共 API 路径、环境变量、Cookie、存储键、插件协议/扩展名/稳定 ID、Go module/import、部署服务和实际镜像来源，除非用户另行明确授权对应迁移。可见英文品牌 SHALL 使用新中文品牌或中性功能说明。

#### Scenario: 原数据与插件继续读取
- **WHEN** 更新后的程序打开旧画布、任务、资源或既有插件包
- **THEN** 原合同和定位键仍有效，不因把技术标识当品牌替换而丢失数据或拒绝导入

### Requirement: 残留审计可复核
交付 MUST 覆盖文本、文件名、包内条目与实际可见素材；所有旧名残留必须有具体位置、类别和理由。必要的迁移输入、测试旧值、机器标识、第三方出处与用户参考文件可作为明确例外，不能把未检查项计作通过。

#### Scenario: 最终搜索与运行验收
- **WHEN** 完成品牌替换并执行最终审计
- **THEN** 产品自有可见品牌无遗漏，例外逐项列出，前后端回归、关键真实路由和包内核验结果可追溯
