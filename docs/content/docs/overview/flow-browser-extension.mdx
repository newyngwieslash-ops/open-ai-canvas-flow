# Flow 浏览器扩展

短剧分镜工作台的「提交到 Flow」支持当前镜头或当前章节。先保存脚本，项目会重新读取服务端当前版本，导出完整视频提示词、镜头语言、对白、动作节拍、画风、接戏备注、已选技能上下文，以及绑定资产和选中/最新分镜图、动作预演图、首尾帧的实际文件。过期素材会保留并标注。

独立扩展位于仓库 `extensions/yingce-flow`，无需构建。Chrome/Edge 开发者模式加载该目录后，点击工具栏的扩展图标，在 Flow 页面旁打开原生侧栏。在「设置」连接影策站点，刷新项目页面，再提交镜头；「镜头」核对素材，「队列」查看运行与下载。源站必须精确授权；仅本机开发允许 HTTP，线上使用 HTTPS。扩展不读取 Google Cookie 或 API Key。

0.1.1 将整页任务入口改为适合窄屏的侧栏。传输完成更新图标数量及已打开的侧栏，不自动打开新标签页。更新时覆盖原扩展目录并在扩展管理页重新加载，关闭旧整页标签后重新点击扩展图标，无需卸载。侧栏宽度和停靠方向遵循浏览器设置。

安装前已打开的 Flow 标签页可能没有页面接收端。「检查页面」会只读检查连接，缺少接收端时尝试补接一次脚本；权限不足或仍失败时提示刷新。生成命令不沿用此重试逻辑，回执丢失仍须核对实际结果。

在同一浏览器的 Flow 项目内选好模型、视频模式、时长、画幅和单次一个输出。首次使用需校准提示框、上传入口、生成按钮和结果区域。扩展预览全部镜头资料，用户选择实际上传素材并确认参数后，按镜头顺序上传、填写、生成、识别结果和下载。当前版本沿用 Flow 页面已设置的参数，不自动调整每镜时长。多格分镜图或动作预演图不会自动裁剪为首帧。

0.1.2 区分 Flow 首页与具体项目页：首页不能用于校准或启动。缺少标记时自动切到「设置」并列出待标记控件，保留已选镜头与素材。每次开始前重新检查当前页面的提示框、生成按钮和专用结果列表，使用素材时额外检查上传入口；失败时尚未创建运行队列或提交生成。标记操作是先点击侧栏的标记按钮，再点击 Flow 中对应位置，最后点击「检查页面」确认。纯文字模式不要求上传入口。

上传标记保留菜单所需的真实点击。点击「标记上传入口」后，点击 Flow 输入框旁的“＋”，再点素材弹窗左下角的 **“Upload media”（上传媒体）**；“Uploads”是素材分类，如弹出文件选择窗口可取消。插件观察新增唯一文件控件或具体上传项实际调用的控件，不自动绑定页面中的其他文件输入。0.1.4 修复侧栏按旧网址过滤导致反馈漏报，改为按本次校准关联并隔离迟到消息；支持准确名称的自定义上传控件，并报告旧生成标记重合。原目录覆盖更新后重新加载插件并刷新 Flow，保留镜头包和原标记，但须重新检查当前 DOM。

0.1.5 补齐独立输入区预检，检查与执行使用同一边界判断。提示框与发送按钮的共同区域包含结果或整页时，会在开始前提示重新标记底部输入框、旁边的发送箭头及输入区之外的结果列表，并显示生成按钮当前指向的文字。位置标记绑定父容器或完整文档路径；支持普通 HTML 表单关联的外部发送按钮。暂停队列的「核对后重试」与「继续队列」重新检查原项目并采用最新校准，不再使用旧标记快照；校验失败保持原暂停状态和镜头包。此改动不跳过附件检查，也不证明未知的 Flow Agent 布局已通过。

媒体以分块传输并验证 SHA-256，存入扩展 IndexedDB；单文件 128 MiB、单包 512 MiB，最多 500 镜和 2000 文件。收到镜头包只进入待确认列表，不会立刻在 Google 生成。状态不明时不会自动重发，下载失败只重试下载；暂停不会取消 Flow 已受理的任务。

视频保存到浏览器下载目录的 `Yingce-Flow/项目名称/`，支持下载镜头与结果清单。当前未实现视频自动回写影策服务端。扩展存储按浏览器配置共享，不跟随影策账号切换清空；卸载会删除包和队列。

页面适配使用真实 DOM 校准。无法确认上传状态、参考附件、提示词或唯一结果时暂停，不猜测结果。0.1.5 的 81 项自动化测试覆盖逻辑及受控 DOM；用户截图确认 Edge 侧栏、包接收和 0.1.4 队列开始后在附件清理前失败。真实输入区校准、上传，以及 Flow Agent 聊天界面的生成与结果关联尚未通过端到端验收，四项标记保存成功不代表付费生成和下载全链路通过。安装步骤、故障处理、实现位置及测试命令见仓库 `extensions/yingce-flow/README.md`。

官方能力参考：[Flow 创建视频](https://support.google.com/flow/answer/16353334?hl=en)、[Flow 模型与支持功能](https://support.google.com/flow/answer/16352836?hl=en)。Flow 各模型可接受的时长、声音和参考输入不同，使用时以页面可用功能为准。
