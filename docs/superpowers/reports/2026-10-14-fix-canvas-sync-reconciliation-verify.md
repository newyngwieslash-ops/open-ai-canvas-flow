## 失败复现与修复

前序测试证明保存期间改标题会误发删除 Agent 节点/连线，并复现纯悬空连线请求重试阻塞。本轮新增四项用例修复前失败：普通编辑和真实删除场景丢失远端新增节点、同字段冲突未拒绝、未知旧基线被直接替换。另一次用例失败源于测试替身误用 nodeId 字段，按真实操作合同 id 修正，未为测试改动生产协议。修复后专项全绿。

后续失败复现命令为 `bun test --cwd web test/user-data-canvas-sync.test.ts`：13 pass、2 fail，两项均在 Agent 刷新抛出“缺少画布合并基线”。第一项是加载确认后本地编辑、重新初始化会话、再收到远端新增节点；第二项是旧缓存远端版本与哈希未变化，刷新仍未恢复。

根因是已确认完整快照只驻留内存，以及打开与 Agent 刷新的基线恢复逻辑不一致。现使用账号隔离 IndexedDB 保存新确认快照及旧投影基线，轮换前先落盘旧投影，恢复时核对 ID、revision、哈希。加载、刷新、增量、保存和全量恢复共用校验；未知基线不猜测，旧 journal 保持原身份。新增覆盖写入失败、发布中断、账号隔离、快照损坏和并行保存范围。助手发送与审批改为仅等待当前画布保存。
