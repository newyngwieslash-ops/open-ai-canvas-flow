# 源铭振跃 Flow 镜头队列

独立的 Chrome / Edge Manifest V3 扩展。0.1.5 使用浏览器原生侧栏，在 Flow 页面旁操作镜头、队列和设置，支持通过“＋ → Upload media”的素材弹窗完成上传标记，并在开始前检查项目页面、控件标记与独立输入区。直接加载本目录，不需要 npm、打包工具或额外服务。

## 安装与使用

1. 如果下载的是 ZIP，先将 ZIP 解压到一个普通文件夹。打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，选中直接包含 `manifest.json` 的文件夹。此窗口只选文件夹，因此看不到 ZIP 或 `manifest.json` 文件是正常的。使用源码时直接选择仓库的 `extensions/yingce-flow` 目录。
2. 点击浏览器工具栏的扩展图标打开侧栏，在「设置 → 项目站点」填写源铭振跃站点的 origin，例如 `http://localhost:5178`，点击连接。线上部署使用 HTTPS。刷新项目页面。
3. 在短剧分镜制作中，先保存脚本，再通过「提交到 Flow」选择当前镜头或当前章节。传输完成会更新图标上的镜头数量，已打开的侧栏会显示新镜头包；侧栏关闭时点击扩展图标查看，不自动打开新标签页。
4. 在同一浏览器配置中登录 Google Flow，打开具体项目。手动选好视频模式、模型、时长、画幅，输出数量设为 **1**。不要在首页启动任务。
5. 保留 Flow 页面，在侧栏「设置」选择当前窗口内的具体项目标签页，依次点击「标记提示框」「标记上传入口」「标记生成按钮」「标记结果区域」，每次再到旁边 Flow 页面点对应控件。结果区域选择视频卡片所在列表的空白处，不选整个页面或单张图片。上传标记时先点击侧栏按钮，再点 Flow 输入框旁的“＋”，继续点素材弹窗左下角的 **“Upload media”（上传媒体）**。“Uploads”是素材分类。出现文件选择窗口时可取消，侧栏显示“已标记上传入口”才算完成。最后点击「检查页面」，确认控件通过。校准位置会保存在本机，页面改版后需重做。
6. 切到侧栏「镜头」，展开各镜头，检查完整提示词、原始时长、过期提示和素材预览。选择实际要上传的文件，并记录 Flow 当前参数。参考素材模式至少选一个文件；首帧模式每镜只能选一张图片；纯文字模式不选文件。
7. 勾选核对确认，开始队列。扩展逐镜填写、上传、点击生成、关联新结果和下载，完成下载后才处理下一镜。请保留该 Flow 标签页，运行期间不要在同页手工生成。

视频默认下载到浏览器下载目录下的 `Yingce-Flow/项目名称/`，按镜头顺序命名。「队列」可显示下载文件位置和下载结果清单，「镜头」可单独下载收到的原素材。清单 JSON 包含元数据和提示词，**不包含二进制文件**。

## 从整页版更新与连接排查

把新版本文件覆盖到原来加载的扩展目录，在扩展管理页点击「重新加载」，刷新 Flow 页面后重新打开侧栏。关闭旧的整页任务标签。侧栏顶部显示 `0.1.5`；不用卸载扩展，原目录和扩展 ID 保持不变时可继续使用本地镜头包及队列。

侧栏的宽度和左右停靠由浏览器管理，内容随宽度自适应。首次进入未配置的插件会显示「设置」，完成配置后默认显示「镜头」。

如果 Flow 标签页在安装插件之前就已打开，「检查页面」会先做只读握手，接收端缺失时补接一次页面脚本。浏览器拒绝访问或仍无法连接时，请检查站点访问权限并刷新 Flow 页面。生成请求失败后不会自动补接并重发；请在「队列」核对实际结果后处理。

## 已收到镜头包，但开始队列被拦住

「请先标记……」表示插件已收到镜头，首次页面校准尚未完成。0.1.2 会自动切到「设置」并聚焦标记区域，保留镜头与素材选择。按上面的第 4–6 步操作；不需要重新上传镜头包。

- Flow 首页和项目列表不能用于生成。先点击已有项目卡片或「New project」，打开具体项目的视频生成页面；标签页列表会区分首页与项目页。
- 保存标记不等于标记仍有效。开始队列前会重新检查当前页面的提示框、生成按钮和专用结果列表；使用素材时还要检查上传控件。检查不通过会返回设置，尚未创建运行队列或点击生成。
- 「Flow 已设置的参数」需要填写你实际选择的模型、时长、画幅和单次输出数量。插件沿用页面已设置的参数。
- 纯文字模式不要求上传入口；参考素材与首帧模式需要该入口。「素材已过期」是供用户核对的警告，不是这次校准拦截的原因。

## 无法确定独立的编辑器区域

这表示提示框与生成按钮的共同容器包含结果列表或整个页面，插件无法把当前附件与历史内容分开。0.1.4 在清理素材前才发现这一问题，因而会出现「检查页面」通过、队列启动后「提交前失败」。报错本身不能证明具体哪个标记选错。

0.1.5 在「检查页面」、开始队列、核对后重试和继续队列时检查输入区，并在失败提示中给出生成按钮当前指向的文字。新标记的位置路径绑定到可识别的父容器或完整文档路径，避免另一工具栏的短位置路径碰巧命中；普通 HTML 表单关联的外部发送按钮也能识别，但不会把包含结果的区域用于附件清理。

更新并刷新 Flow 后，在原项目重新标记底部提示框及其旁边的发送箭头，结果区域选输入框之外的视频结果列表。点击「检查页面」通过后，到「队列 → 核对后重试 → 继续队列」。旧队列会读取最新校准，不再沿用开始时的旧标记；检查不通过时保持暂停。镜头包与素材选择保留，不必重新导入。没有边界证据时仍会拦截，不跳过清理或扩大到整页操作；真实 Flow Agent 布局仍须验收。

## 点击“＋”无法标记上传入口

Flow 输入框旁的“＋”是添加素材入口，通常还需要在展开的菜单中点击上传文件。旧版校准拦截鼠标按下事件，再补发一次 `click`；依赖 `pointerdown` 的菜单可能打不开，只有加号的控件也可能被拒绝。

上传标记保留用户对上传按钮和菜单项的真实点击，不补发点击。插件观察新出现的唯一文件控件，或捕获所选上传项实际调用的文件控件；不会因为页面上恰好只有一个文件控件就自动绑定它。0.1.4 支持“Upload media”的按钮和自定义文字控件，并把“Uploads”分类与实际上传动作分开提示。旧生成标记误指向当前位置时会要求重新标记生成按钮，不继续点击。

0.1.3 的侧栏按缓存的完整网址筛选消息，页面网址变化可能导致校准错误漏报。0.1.4 改为按本次校准 ID 和所选标签页关联；开始回执之前的状态会补读，迟到的旧消息不覆盖新结果。等待、完成、多个目标和超时均会显示在侧栏。

更新并刷新 Flow 后，重新执行“标记上传入口 → Flow 的＋ → 素材弹窗左下角 Upload media”。原来的其他标记和镜头包保留；仍需用「检查页面」确认它们在当前页面有效。若关闭菜单后上传控件消失，请重新展开菜单再检查；不能只凭“已保存 4/4”判断可以运行。

## 数据与提示词

项目按已保存的当前脚本版本从服务端读取数据，未保存编辑会阻止导出。镜头包包括：

- 项目、章节、镜头、脚本版本 ID；完整脚本字段及原始动作节拍。
- 可读的完整视频提示词：视频描述、镜头画面、表演与动作、对白、景别/机位/运镜、目标时长、项目画风、画面提示词、排除内容、接戏备注、引用资产说明。
- 当前所选技能通过项目现有 `skillRuntime.prepare(shortDrama)` 编入提示词；这不会执行技能脚本，也不会再调用模型改写提示词。
- 绑定版本的角色/场景/道具参考文件及可用表现图，当前角色声音样本；当前选中和最新的分镜图、动作预演图、首尾帧。有多个资源身份共用同一文件时，额外映射保留在警告中。
- 过期与旧版本信息、文件类型、大小及 SHA-256。不会把过期文件静默换成新文件。

「动作预演」在当前源铭振跃实现中是图片；分镜图也可能是多格图。完整导出不代表把每个文件都用作首帧。插件保留所有导出文件，Flow 只接收用户勾选的输入。项目资产 token 会变成可读名称，执行时补充真实上传文件名映射。

单文件上限 128 MiB，单包 512 MiB，最多 500 镜 / 2000 个文件。文件以 256 KiB 分块发送，全部校验后才发布到插件待确认列表；大文件放 IndexedDB，不放 localStorage 或同步存储。传输过程中断不会启动 Google 生成。

## 当前边界

- 使用 Flow 当前登录态和页面控件，不读取 Cookie/Token，不使用未公开的 Google 接口。首次校准、初始视频模式和参数设置需要人工完成；当前版本不会自动切换每镜时长、裁剪多格图或把参考图创建为 Flow 角色 `@` 对象。
- 不同 Flow 模型支持的时长、素材数量、音频和参考模式不同。原始镜头的 5 秒不等于 Flow 可以生成 5 秒；请在任务页核对。扩展不静默裁剪、转码或减少参考素材。
- 仅支持顶层页面中的普通 DOM 控件；不支持 iframe/Shadow DOM 内的编辑器。上传控件、完成状态或参考附件无法可靠识别时停止，需人工检查和重新校准。
- 结果识别要求专用结果列表中出现新视频卡片，且卡片文本包含本次提示词的识别片段。页面只展示缩略图、隐藏提示词、虚拟列表复用旧节点或存在多个匹配结果时，无法自动关联，队列会暂停。不能把最后一个视频无条件当成本镜结果。
- Flow Agent 聊天界面尚未完成专门的生成与结果关联适配验收；上传标记成功不代表聊天模式下的生成、结果识别和下载已经通过。
- 暂停/结束只阻止后续自动操作，不取消 Flow 已经受理的生成。提交回执丢失、标签页刷新、登录失效或超时不会自动重发。请在 Flow 核对后选择重试或跳过；重试可能再次扣费。
- 下载失败保留已生成结果，支持「只重试下载」，不会重新生成。临时地址失效或浏览器禁止下载时，需要从 Flow 自行下载。
- 视频不会自动回写源铭振跃服务端或挂到镜头产物中；本版完成到本机下载和带镜头 ID 的结果清单。扩展没有独立账号系统，当前浏览器配置中的使用者能访问此前导出的镜头包；卸载扩展会删除本地包和任务。

## 验证

从仓库根目录运行：

```powershell
node --test extensions/yingce-flow/tests/*.test.mjs
```

DOM 适配测试使用项目已安装的 `web/node_modules/happy-dom`；测试中替换浏览器 API，不访问 Google，不产生费用。这些测试覆盖传输与校验、来源权限、逐镜队列、重复提交保护、DOM 填写和结果匹配等，不能替代真实 Chrome/Edge 加载和 Flow 付费端到端验收。

0.1.5 独立发布分支已重新验证：扩展 81 项测试、项目侧 18 项测试（205 次断言）及完整前端构建（含 TypeScript 检查）通过。覆盖输入区预检、外部表单发送按钮、嵌套输入区、位置标记隔离、重新校准后旧队列重试/继续使用新标记、跨项目和上传未就绪拦截，并保留上传菜单、传输、提交去重与结果关联回归。构建提示大 chunk、动态导入和插件耗时警告；补充执行的 `bun run lint` 因本地 Babel 依赖缺少 `validators/react/isReactComponent.js` 无法解析，未通过。既有截图记录确认 0.1.4 到达队列启动，随后在清理参考素材前失败；不能据此认定文件已上传到 Google 或视频已生成。0.1.5 真实输入区校准、上传、付费生成和下载仍待验收。

## 实现位置

- `manifest.json`、`source-bridge.js`：受限站点权限与同源页面消息桥。
- `core.mjs`、`db.mjs`、`worker.js`：数据合同、二进制持久化、任务状态机和下载。
- `flow-content.js`：Flow 控件校准、填写上传、提交与结果观察。
- `dashboard.html`、`dashboard.js`、`dashboard.css`：原生侧栏的镜头、队列与设置，连接、预览和输入用途选择。
- 项目侧 `web/src/services/flow-bridge.ts`、`web/src/pages/projects/detail/workflow-flow-export.ts` 与分镜工作台按钮。
